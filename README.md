## ✨ Features

* 🔤 **Text to Morse Code Conversion**: Translate letters from A–Z into their corresponding Morse code sequences.
* ⚡ **Instant Conversion**: Convert your input directly in the terminal.
* 🐍 **Pure Python**: Built using basic Python concepts, including dictionaries, loops, and user input.
* 🎯 **Simple and Lightweight**: No external libraries or dependencies required.
* 💻 **Command-Line Interface**: Enter a word and receive its Morse code output directly in the terminal.

## 🚀 Quick Start

Follow these steps to run the program locally.

### Prerequisites

* **Python 3** or higher
* A terminal or command prompt
* Git (optional)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/is4r0/text-to-morse-code.git
   ```

2. **Navigate to the project directory**

   ```bash
   cd text-to-morse-code
   ```

3. **Run the program**

   ```bash
   python morse.py
   ```

   If your system uses the `python3` command, run:

   ```bash
   python3 morse.py
   ```

4. **Enter your text**

   When prompted, enter a word and the program will display its Morse code equivalent.
